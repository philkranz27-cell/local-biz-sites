Häufige Fragen

Ich habe Ihnen einen Entwurf geschickt — woher haben Sie meine Daten?

Aus frei zugänglichen Quellen: Name, Adresse und Kontaktdaten stammen aus OpenStreetMap, einer offenen Kartendatenbank. Wenn Sie keine weitere Nachricht von mir wünschen, schreiben Sie mir kurz — dann trage ich Sie ein und Sie hören nichts mehr von mir.

Ist der Entwurf wirklich kostenlos?

Ja. Sie zahlen erst, wenn Sie die Seite haben wollen. Sagen Sie ab, entstehen Ihnen keine Kosten.

Was passiert, wenn ich später kündige?

Die monatliche Betreuung ist jederzeit zum Monatsende kündbar. Ihre Inhalte und die fertige Seite bekommen Sie auf Wunsch ausgehändigt.

Brauche ich eine eigene Internetadresse?

Nicht zwingend — ich kann die Seite unter einer Adresse von mir bereitstellen. Eine eigene Adresse (z.B. ihr-betrieb.de) ist aber empfehlenswert; ich richte sie auf Wunsch ein, die Gebühr des Anbieters kommt dann dazu.
